# Python Syntax & Language Fundamentals

This folder contains foundational notebooks covering Python's core data types, operators, and control flow logic.

---

## 📚 Topics Covered
1. **Data Types & Variables**:
   - Numeric types: `int`, `float`, `complex`.
   - Sequence types: `str`, `list`, `tuple`, `range`.
   - Mapping & Set types: `dict`, `set`, `frozenset`.
   - Mutability vs. Immutability, deep vs. shallow copy (`copy.deepcopy`).
2. **Conditionals & Looping**:
   - `if`, `elif`, `else` branch logic.
   - `for` loops, `while` loops, `break`, `continue`, `pass`, and loop `else` clauses.
   - List, dictionary, and set comprehensions.
