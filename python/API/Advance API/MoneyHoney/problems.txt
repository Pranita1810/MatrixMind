1. How to connect ORM if there are multiple tables in database ?
-  We use "sqlacodegen", which is an automatic model code generator for SQLAlchemy.
   It is a command line tool written in python that reads structure of an existing db and create python 
   class models. So you do not have to write n numbers of classes for n numbers of tables.
   <sqlacodegen "mssql+pyodbc://yourid:password@localhost:1433/STOCK_DATA?driver=ODBC+Driver+17+for+SQL+Server" > app/db/models/generated_models.py>
   use this command to generated_models.
