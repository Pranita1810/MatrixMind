1. Problem Statement : we have so many clients and lots of data to Response from db.
Solution :
Client
  ↓
Reverse Proxy / CDN
  ↓
API Gateway
  ├── Authentication
  ├── Rate Limiting
  └── Routing
  ↓
Nginx Load Balancer
  │
  ├── FastAPI Server 1
  ├── FastAPI Server 2
  └── FastAPI Server 3
           │
           ↓
      Shared Redis
           │
           ↓
        Database
           │
      Pagination
           ↓
        Response
