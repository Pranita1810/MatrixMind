    Become a production-level API builder

    A 16-phase path from your first endpoint to a tested, monitored, deployed API. Every step from your original plan is here, and each phase adds a build exercise, common mistakes, self-check questions, a code example and reading. Tick steps as you finish them; progress is saved in this browser.

    Before you start

    • Python: functions, classes, type hints, virtual environments, exceptions.
    • HTTP: methods, headers, status codes, cookies, what TLS does.
    • SQL: joins, GROUP BY, indexes, transactions. Write queries by hand before trusting an ORM.
    • Git, the Linux command line, and Docker basics (images vs containers).

    Study loop for every step

    1. Read the official docs for the component (20 min).
    2. Build it in your one running project, not a throwaway demo.
    3. Break it on purpose: bad input, killed process, slow dependency.
    4. Test the failure so it can never silently come back.
    5. Write down one decision and why (a short ADR in docs/).

    Capstone: Orders & Inventory API

    One project that touches every phase. Build it once, then keep strengthening it. Your original goal of data engineering fits in the import job.

    What it does

    • Users register, log in and manage their own orders.
    • Admins manage products and stock; stock can never go negative.
    • Placing an order reserves stock inside one transaction and is safe to retry (idempotency key).
    • Admins upload a products CSV; a worker validates and loads it in chunks with a visible job status.

    Milestones

    • Week 1: products CRUD, pagination, filtering, OpenAPI contract.
    • Week 2: orders, services, JWT auth, ownership checks, 30+ tests.
    • Week 3: request IDs, rate limits, Redis cache, CSV import job.
    • Week 4: Docker, CI/CD, staging, metrics, backup and restore drill.
    Stretch goals once it ships: optimistic locking on stock, an outbox table for order events, a load test report with p95 latency, and a written postmortem of one failure you caused on purpose.
