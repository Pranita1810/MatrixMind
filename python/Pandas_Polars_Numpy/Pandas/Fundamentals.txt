***** PANDAS FUNDAMENTALS *****

-- Overview --
Pandas is Python's premier data manipulation and analysis library, built on top of NumPy.
It introduces high-performance, flexible tabular data structures: the 1D Series and the 2D DataFrame.

-- Top 10 Core Concepts & Idiomatic Syntax --

1. Data Loading & Inspection:
	- pd.read_csv("data.csv"), pd.read_excel("data.xlsx"), pd.read_parquet("data.parquet")
	- df.head(5), df.tail(5)
	- df.info()        # Schema, null counts, memory usage
	- df.describe()    # Numerical summary statistics
	- df.shape         # Tuple (rows, columns) - Property, NOT a function

2. Data Selection & Slicing:
	- df["column_name"]                      # Single column (Series)
	- df[["col1", "col2"]]                   # Multiple columns (DataFrame)
	- df.loc[row_labels, column_names]       # Label-based indexing
	- df.iloc[row_indices, column_indices]   # Integer position-based indexing

3. Filtering & Boolean Indexing:
	- df[df["age"] > 25]
	- df[(df["status"] == "active") & (df["score"] >= 80)]   # Logical AND (&), OR (|), NOT (~)
	- df[df["category"].isin(["Tech", "Finance"])]
	- df[df["name"].str.contains("John", case=False, na=False)]
	- df[df["salary"].between(50000, 100000)]

4. Data Cleaning & Null Handling:
	- df.isna().sum()                        # Missing value count per column
	- df.dropna(subset=["critical_col"])     # Drop missing rows
	- df["age"] = df["age"].fillna(df["age"].median())   # Impute with median / mean()
	- df.drop_duplicates(subset=["id"], keep="first")    # Remove duplicate rows

5. GroupBy & Aggregations:
	- df.groupby("department")["salary"].mean()
	- df.groupby("region").agg(total_sales=("sales", "sum"), avg_order=("sales", "mean"), orders=("order_id", "count"))

6. Feature Engineering & Column Transformations:
	- df["total_cost"] = df["quantity"] * df["unit_price"]
	- df["tier"] = df["spend"].apply(lambda x: "High" if x > 1000 else "Standard")

7. Merging, Joining & Concatenation:
	- df_merged = pd.merge(df1, df2, on="user_id", how="left")  # inner, left, right, outer
	- df_concat = pd.concat([df1, df2], axis=0, ignore_index=True)

8. Date-Time Parsing & Operations:
	- df["timestamp"] = pd.to_datetime(df["timestamp"], errors="coerce")
	- df["year"] = df["timestamp"].dt.year
	- df["month"] = df["timestamp"].dt.month_name()
	- df["day_of_week"] = df["timestamp"].dt.day_name()

9. Sorting & Ranking:
	- df.sort_values(by="revenue", ascending=False)
	- df.sort_values(by=["department", "salary"], ascending=[True, False])
	- df.nlargest(5, "salary") / df.nsmallest(5, "salary")

10. Reshaping & Pivot Tables:
	- df.pivot_table(values="sales", index="region", columns="quarter", aggfunc="sum", fill_value=0)
	- df.melt(id_vars=["date"], value_vars=["sales_A", "sales_B"], var_name="store", value_name="revenue")
